Sources et références officielles

Cette annexe liste les sources officielles consultées pour la rédaction de ce livre. Toutes les informations techniques (tarifs, fonctionnalités, spécifications, commandes) ont été vérifiées sur ces sources en octobre 2026.

Une adresse web est ce qu'un livre imprimé contient de plus fragile : les éditeurs réorganisent leurs sites, renomment leurs pages et redirigent les anciennes jusqu'au jour où ils cessent de le faire. Les adresses ci-dessous sont donc données pour ce qu'elles sont, l'état d'un relevé daté. Deux habitudes les remplacent le jour où l'une tombe. Cherchez le titre de la page, reproduit ici à chaque fois, dans le moteur de recherche du site de l'éditeur : c'est le titre qui survit, pas le chemin. Commencez aussi par la page de ressources en ligne de ce livre, qui tient cette même liste à jour et signale ce qui a bougé.

Anthropic et Claude Code

Documentation officielle Claude Code https://code.claude.com/docs/fr/overview La référence principale pour toutes les fonctionnalités de Claude Code : installation, commandes, agents, MCP, personnalisation. C'est la source qu'Anthropic tient à jour, et donc celle qui prime sur ce livre partout où les deux divergent.

Carte de la documentation Claude Code https://code.claude.com/docs/en/claude_code_docs_map.md Index complet de toutes les pages de documentation Claude Code. Point d'entrée recommandé pour une recherche précise.

Documentation API et modèles Anthropic https://platform.claude.com/docs/fr/ Documentation complète de l'API Anthropic : modèles disponibles (les familles Fable, Opus, Sonnet et Haiku), fenêtres de contexte, tarification à la consommation, paramètres avancés.

Tarifs et plans Anthropic https://claude.com/fr/pricing Tarifs officiels des abonnements et de la facturation à la consommation. Les ordres de grandeur cités au chapitre 4 en viennent. Aucun chiffre de ce livre ne doit servir de base à une décision d'achat : c'est cette page qui fait foi, et elle change.

Cours gratuits Anthropic https://academy.claude.com Les formations en ligne publiées par Anthropic, dont une consacrée à Claude Code. Comptez une à deux heures. Le catalogue, la langue et les conditions d'accès se lisent sur place : ils étaient en anglais et sans condition en août 2026. Citée à la section 4.1.

Usages courants de Claude Code https://code.claude.com/docs/fr/common-workflows Recettes officielles par tâche. C'est sur cette page qu'Anthropic énonçait, au moment du relevé, que Claude Code travaille dans n'importe quel dossier, carnet de notes et répertoires de documents compris, et non dans les seuls projets de programmation. Si la page a été réorganisée, l'affirmation se retrouve dans la documentation d'ensemble de l'outil. Citée dans la préface et au chapitre 1.

Guide pratique Claude Code (source secondaire) https://ccforeveryone.com/ Guide indépendant sur les fonctionnalités, commandes slash et raccourcis de Claude Code. Utilisé en complément de la documentation officielle pour les chapitres 4, 5 et 19. Source secondaire, et tenue par un tiers : rien ne garantit qu'elle sera maintenue. En cas de divergence, la documentation officielle tranche.

Microsoft Copilot

Vue d'ensemble Microsoft Copilot Chat https://learn.microsoft.com/fr-fr/copilot/microsoft-copilot Documentation officielle de Copilot Chat (version gratuite incluse avec les licences Microsoft 365). Décrit les capacités de conversation, de chargement de fichiers et d'accès aux données.

Microsoft 365 Copilot, vue d'ensemble https://learn.microsoft.com/fr-fr/copilot/microsoft-365/microsoft-365-copilot-overview Documentation de la version payante de Copilot intégrée dans Word, Excel, PowerPoint, Outlook et Teams. Décrit l'accès aux données organisationnelles via Microsoft Graph.

Chargement de fichiers dans Microsoft Copilot https://support.microsoft.com/fr-fr/topic/chargement-de-fichiers-dans-microsoft-copilot-8b7bf432-9576-4b16-9dee-6c19a4169e62 Documentation officielle sur les limites de chargement de fichiers. Elle annonçait en août 2026 une vingtaine de fichiers par conversation et quelques dizaines de mégaoctets par fichier, pour une liste de formats bureautiques courants ; ces plafonds bougent, lisez-les sur la page. Attention en la citant : cette page décrit Microsoft Copilot, l'offre grand public, et non Copilot pour Microsoft 365, dont les limites dépendent de la formule souscrite. C'est la raison pour laquelle le chapitre 1 ne reprend plus ces chiffres.

Copilot dans Teams, réunions https://support.microsoft.com/fr-fr/office/use-copilot-in-microsoft-teams-meetings-0bf9dd3c-96f7-44e2-8bb8-790bedf066b1 Conditions d'utilisation de Copilot pour les résumés de réunion Teams : transcription requise pour tout usage après la réunion, contrôle par l'organisateur, récapitulatif intelligent soumis à une licence Microsoft 365 Copilot ou Teams Premium. La page ne fixe aucune durée minimale de réunion : les cinq minutes qu'on y lit désignent le retard au-delà duquel Copilot propose un rattrapage à un participant arrivé en cours de séance.

Architecture Microsoft 365 Copilot https://learn.microsoft.com/fr-fr/microsoft-365/copilot/microsoft-365-copilot-architecture Explication technique du fonctionnement de M365 Copilot : accès aux données via Microsoft Graph, technique de grounding (prétraitement des requêtes avec le contexte utilisateur), respect des politiques de sécurité (Conditional Access, MFA). Lecture recommandée pour comprendre pourquoi Copilot voit les données M365 mais pas les fichiers externes.

Copilot pour tous, annonce Copilot Chat (Microsoft News, janvier 2025) https://news.microsoft.com/source/emea/2025/01/copilot-pour-tous-voici-microsoft-365-copilot-chat/?lang=fr Annonce officielle du lancement de Copilot Chat gratuit, avec le modèle OpenAI de l'époque et le chargement de fichiers inclus. Explique la distinction entre Copilot Chat (accès gratuit, chargement manuel) et Microsoft 365 Copilot (licence payante, accès aux données organisationnelles via Microsoft Graph).

Copilot Studio https://learn.microsoft.com/fr-fr/microsoft-copilot-studio/ Documentation de Copilot Studio, l'outil de création d'agents personnalisés Microsoft. Distinct de Copilot M365 : nécessite une licence séparée.

Tarifs Microsoft 365 Copilot https://www.microsoft.com/fr-fr/microsoft-365/microsoft-365-copilot Tarification officielle des offres Copilot Business (add-on M365) et Copilot Enterprise.

Outils tiers mentionnés dans le livre

Node.js (chapitres 4 et 20) https://nodejs.org Moteur d'exécution. Deux usages le réclament : installer Claude Code en ligne de commande (section 4.8) et activer un connecteur MCP ajouté par commande (section 20.2), votre poste exécutant alors le programme du connecteur. Un connecteur pris dans la liste de l'application, hébergé chez son éditeur, n'en demande pas. Les tâches du livre, elles, n'en réclament aucun : produire un document Word suppose un composant que Claude Code installe lui-même à la première exécution, sans que vous ouvriez de terminal. Chaque prompt porte sa voie de secours en HTML si votre poste refuse cette installation (section 4.1). Téléchargez toujours la version LTS (Long Term Support).

n8n (page de ressources en ligne) https://n8n.io Outil d'automatisation extérieur. Ce livre ne l'emploie nulle part : il n'est utile qu'au seul besoin que les tâches programmées du chapitre 20 ne couvrent pas, celui d'un travail qui doit partir ordinateur éteint tout en voyant des fichiers. Distribué sous une licence dite fair-code, qui n'est pas une licence open source au sens de l'Open Source Initiative : vérifiez les conditions d'usage et les offres en cours sur n8n.io avant de vous engager.

Pandoc https://pandoc.org Outil gratuit de conversion de documents. Facultatif : aucun chapitre de ce livre ne l'exige. Claude Code produit lui-même les documents Word. Quand il n'y parvient pas, la voie de secours inscrite dans chaque prompt passe par un fichier HTML que Word sait ouvrir. Pandoc ne sert qu'à ceux qui convertissent souvent ; il s'utilise en ligne de commande et son installation peut demander l'accord de votre service informatique.
