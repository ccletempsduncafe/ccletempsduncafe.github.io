Sources et références officielles

Cette annexe liste les sources officielles consultées pour la rédaction de ce livre. Toutes les informations techniques (tarifs, fonctionnalités, spécifications, commandes) ont été vérifiées sur ces sources en août 2026. L'écosystème des assistants d'IA évolue rapidement : certaines de ces informations ont peut-être changé depuis la publication. Consultez les URL ci-dessous pour les données à jour.

📅 Cette annexe a été constituée en août 2026. Via le QR code en fin de livre, retrouvez la version mise à jour de cette liste de ressources.

Anthropic et Claude Code

Documentation officielle Claude Code https://docs.anthropic.com/en/docs/claude-code/overview La référence principale pour toutes les fonctionnalités de Claude Code : installation, commandes, agents, MCP, personnalisation. Mise à jour en continu par Anthropic.

Carte de la documentation Claude Code https://docs.anthropic.com/en/docs/claude-code/claude_code_docs_map.md Index complet de toutes les pages de documentation Claude Code. Point d'entrée recommandé pour une recherche précise.

Documentation API et modèles Anthropic https://platform.claude.com/docs/fr/ Documentation complète de l'API Anthropic : modèles disponibles (Claude Opus 4.6, Claude Sonnet 4.6, Claude Haiku 4.5), fenêtres de contexte, tarification à la consommation, paramètres avancés.

Tarifs et plans Anthropic https://claude.com/pricing Tarifs officiels des abonnements Claude Pro et Claude Max, et de l'API à la consommation. Consultez cette page avant toute décision d'achat : les prix sont régulièrement mis à jour.

Guide pratique Claude Code (source secondaire) https://ccforeveryone.com/ Guide indépendant sur les fonctionnalités, commandes slash et raccourcis de Claude Code. Utilisé en complément de la documentation officielle pour les chapitres 4, 5 et 21.

Microsoft Copilot

Vue d'ensemble Microsoft Copilot Chat https://learn.microsoft.com/fr-fr/copilot/microsoft-copilot Documentation officielle de Copilot Chat (version gratuite incluse avec les licences Microsoft 365). Décrit les capacités de conversation, de chargement de fichiers et d'accès aux données.

Microsoft 365 Copilot — vue d'ensemble https://learn.microsoft.com/fr-fr/copilot/microsoft-365/microsoft-365-copilot-overview Documentation de la version payante de Copilot intégrée dans Word, Excel, PowerPoint, Outlook et Teams. Décrit l'accès aux données organisationnelles via Microsoft Graph.

Chargement de fichiers dans Microsoft Copilot https://support.microsoft.com/fr-fr/topic/chargement-de-fichiers-dans-microsoft-copilot-8b7bf432-9576-4b16-9dee-6c19a4169e62 Documentation officielle sur les limites de chargement de fichiers dans Copilot : 20 fichiers maximum par conversation, 50 Mo par fichier, formats supportés (PDF, DOCX, XLSX, PPTX, TXT, CSV, PNG, JPEG).

Copilot dans Teams — réunions https://support.microsoft.com/en-us/office/use-copilot-in-microsoft-teams-meetings-0bf9dd3c-96f7-44e2-8bb8-790bedf066b1 Conditions d'utilisation de Copilot pour les résumés de réunion Teams : transcription requise, durée minimale de 5 minutes, configuration par l'organisateur.

Architecture Microsoft 365 Copilot https://learn.microsoft.com/fr-fr/microsoft-365/copilot/microsoft-365-copilot-architecture Explication technique du fonctionnement de M365 Copilot : accès aux données via Microsoft Graph, technique de grounding (prétraitement des requêtes avec le contexte utilisateur), respect des politiques de sécurité (Conditional Access, MFA). Lecture recommandée pour comprendre pourquoi Copilot voit les données M365 mais pas les fichiers externes.

Copilot pour tous — annonce Copilot Chat (Microsoft News, janvier 2025) https://news.microsoft.com/source/emea/2025/01/copilot-pour-tous-voici-microsoft-365-copilot-chat/?lang=fr Annonce officielle du lancement de Copilot Chat gratuit (GPT-4o, upload de fichiers inclus). Explique la distinction entre Copilot Chat (accès gratuit, chargement manuel) et Microsoft 365 Copilot (licence payante, accès aux données organisationnelles via Microsoft Graph).

Copilot Studio https://learn.microsoft.com/en-us/microsoft-copilot-studio/ Documentation de Copilot Studio, l'outil de création d'agents personnalisés Microsoft. Distinct de Copilot M365 : nécessite une licence séparée.

Tarifs Microsoft 365 Copilot https://www.microsoft.com/fr-fr/microsoft-365/microsoft-365-copilot Tarification officielle des offres Copilot Business (add-on M365) et Copilot Enterprise.

Outils tiers mentionnés dans le livre

Node.js — Chapitres 5, 21 et 22 https://nodejs.org Moteur d'exécution requis pour installer Claude Code en ligne de commande (section 5.7), pour activer un connecteur MCP (section 21.2), pour lancer un agent depuis le terminal (section 22.6) et pour installer n8n localement (section 21.5). Les treize cas d'usage du livre se pratiquent dans l'application de bureau et n'en demandent pas. Node.js redevient nécessaire dès que vous sortez de ce cadre, y compris pour activer un connecteur MCP depuis l'application, un connecteur étant un petit programme que votre poste exécute. Téléchargez toujours la version LTS (Long Term Support).

n8n — Chapitre 21 https://n8n.io Outil d'automatisation permettant de connecter Claude à des services externes (email, calendrier, Slack, Notion). S'installe sur votre machine ou s'utilise en ligne. Distribué sous une licence dite fair-code, qui n'est pas une licence open source au sens de l'Open Source Initiative : vérifiez les conditions d'usage et les offres en cours sur n8n.io avant de vous engager.

Pandoc — Chapitres 11 et 18 https://pandoc.org Outil gratuit de conversion de documents. Facultatif : aucun chapitre de ce livre ne l'exige, la conversion vers Word par la voie HTML décrite à la section 11.5 suffit et ne demande rien à installer. Pandoc ne sert qu'à ceux qui convertissent souvent ; il s'utilise en ligne de commande, et son installation peut demander l'accord de votre service informatique.

Outils de fabrication du livre

Ces outils ne sont pas nécessaires à la lecture ni à la pratique des chapitres. Ils sont cités pour la transparence sur la fabrication de l'ouvrage.

Vellum — https://vellum.pub Logiciel de mise en page pour l'auto-publication (Mac uniquement, achat unique). Mise en page finale du manuscrit, export PDF pour l'impression et ePub pour la liseuse.

Excalidraw — https://excalidraw.com Outil de création de schémas à l'aspect dessiné à la main, utilisé pour les schémas explicatifs, exportés en PNG.
